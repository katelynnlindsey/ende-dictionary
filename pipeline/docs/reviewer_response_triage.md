# Reviewer response triage

Every concrete, actionable point from the two Pacific Linguistics reviews, cross-checked against the current `ende.lift` export and the pipeline. Each item is tagged:

- **[CODE -- done]**: fixed this session, already in the pipeline.
- **[CODE -- ready]**: a concrete, code-detectable/fixable change proposed but not yet applied (needs your sign-off, since it changes published content/presentation).
- **[FLEX]**: requires correcting the underlying FLEx database -- content-level, not something code can infer.
- **[POLICY]**: a structural/editorial decision only you can make; code can surface candidates but not decide.
- **[UNCLEAR]**: checked against current data and could not reproduce / needs clarification.
